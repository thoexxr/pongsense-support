随 App 分发的模型文件

PongSense v1.0 的 App 包内包含以下三个 Core ML 模型（.mlpackage），全部在设备本地推理、不联网。三个模型均为 Apache License 2.0 许可的开源模型。

文件用途许可开源来源
yolox.mlpackage 乒乓球检测（逐帧目标检测，单类） Apache License 2.0 Megvii YOLOX（YOLOX-tiny 结构）；检测头的权重由本项目使用自有标注数据微调，训练数据为自采视频与公开可商用数据
RTMO_Dense.mlpackage 人体骨架关键点（17 点，多人） Apache License 2.0 OpenMMLab mmpose — RTMO（Real-Time Multi-Person Pose Estimation, one-stage）
RTMO_DCC.mlpackage 人体骨架关键点（同上，另一组推理配置，用于不同帧尺寸/人数密度） Apache License 2.0 OpenMMLab mmpose — RTMO

模型文件只包含网络结构与权重，不含任何用户数据；App 不会把推理输入或输出上传到服务器。

English

Bundled models (all Apache License 2.0, all inference on-device):

  • yolox.mlpackage — table-tennis ball detector, YOLOX-tiny architecture (Megvii YOLOX); head fine-tuned by the author on self-collected and commercially usable data.
  • RTMO_Dense.mlpackage / RTMO_DCC.mlpackage — multi-person pose estimation, OpenMMLab mmpose RTMO.

Skeleton pipeline: the pose models plus RTMODecode.swift, a Swift port of mmpose's RTMO post-processing (SimCC decoding, coordinate mapping, keypoint score thresholding). Keypoint layout follows the COCO 17-keypoint order. Player selection, skeleton rendering, table calibration, ball filtering and stroke classification are original code by the author; StrokeRules.swift is a geometric rule scorer and contains no third-party weights.

Not shipped in v1.0: the ST-GCN stroke classifier (stgcn.mlpackage, trained on CC BY-NC-SA 4.0 data) and the demo videos (demo_singles.mp4, demo_doubles.mp4) were removed before submission and are not part of the App Store build.
